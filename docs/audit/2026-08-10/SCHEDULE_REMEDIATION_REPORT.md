## 管理摘要

本輪已關閉原完整度稽核列出的全部 P1 與 P2 可重現缺口，且未刪除或改寫既有正式資料。系統現在具備公版班表預覽／匯入、相容匯出、最終發布重驗、跨表單加班累計、台灣加班費分段計算、國定假日挪移證據、穩定語義欄位及安全搜尋。

綜合工程評分由 **6.8/10 提升至 9.0/10**。此分數代表目前程式與測試證據，不取代台灣勞務或法務對個別行業、變形工時核備文件與公司規章的正式確認。

## 規範結果

- 每週一至日一例一休：發布前強制執行，不能由設定關閉。
- 班與班間隔：預設至少 11 小時；8 小時例外必須先設定核准依據。
- 每日工時：正常 8 小時、加班最多 4 小時、合計不得超過 12 小時。
- 加班總量：一般每月 46 小時；例外上限 54 小時且滾動三個月不得超過 138 小時，必須有核准依據。
- 休息日可加班；例假日不得排加班或延時打卡。
- 特休、國定假日、補休、病假、喪假、公假、事假與原民假均會納入連續出勤序列，不會把請假誤當例假或休息日。
- 臨時調班、批次覆蓋、Excel 匯入及最終發布均會重新檢核，不符合即拒絕寫入或完成發布。

## 上線注意

本次模型變更均為向後相容的新增欄位，不需要刪除或重建 MongoDB。部署時需执行 `npm ci`、前端 `npm run build`，并重新启动 PM2。Linux 主机应安装繁中字型或设置 `PDF_FONT_PATH`；系统会在字型缺失时明确失败，避免生成不可读薪资文件。

HTTP 暂依项目决定延后处理；正式 domain 上线时仍必须启用 HTTPS、安全 Cookie 与反向代理安全标头。变形工时、11 小时间隔例外及延长加班额度只有在适用行业和法定程序成立时才可启用。
