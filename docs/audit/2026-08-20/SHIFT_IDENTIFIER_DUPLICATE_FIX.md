# 班別代碼與重複名稱修正紀錄

日期：2026-08-20  
來源：客戶回報班別設定欄位意義不清，並詢問公版班表匯入是否應禁止重複名稱。

## 欄位定義

- 班別代碼：公版 Excel 班表在每日欄位填寫的匯入識別鍵，例如 `D`、`E`、`N`。
- 班別名稱：顯示於班別設定、班表及報表的人類可讀名稱，例如「日班」、「夜班」。
- 為避免匯入歧義，代碼與名稱經去除前後空白、全形半形正規化及英文大小寫統一後，必須在所有班別識別值中唯一。
- 系統仍相容既有以班別名稱填寫的檔案，但正式公版建議只使用班別代碼。

## 修正內容

1. 班別列表欄位改為「班別代碼（匯入）」，新增及編輯視窗补充代码用途。
2. 前端送出前检查重复代码、重复名称及代码/名称交叉冲突，冲突时不发送 API。
3. 后端新增及编辑再次检查唯一性，冲突回传 `409` 与 `SHIFT_IDENTIFIER_CONFLICT`，且不保存。
4. Excel 汇入使用相同正规化与映射规则；只有档案实际用到歧义识别值时才拒绝，不影响其他唯一代码。
5. 设置页会列出现存历史冲突，让管理员知道应修改哪两笔班别。
