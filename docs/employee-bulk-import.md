# 員工批量匯入

後台「人資管理 → 匯入員工資料」：上傳 `.xlsx` / `.csv`，一次建立或更新多位員工。

## 檔案格式

- 第 1 列：英文欄位名（如 `employeeId`、`name`、`email`）。
- 第 2 列：中文說明（只用來辨識，不匯入）。
- 第 3 列起：資料。
- 必填：員工編號、姓名、Email、身分證號。

### 後加欄位的備援讀法

特休與勞健保投保欄位若在第 1 列沒有英文欄位名，系統會改用第 2 列的中文名稱比對，不需要手動改表頭：

| 第 2 列中文名稱 | 對應欄位 |
| --- | --- |
| 年度特休總天數 | `annualLeave_totalDays` |
| 已使用天數 | `annualLeave_usedDays` |
| 積假 | `annualLeave_accumulatedLeave` |
| 請假期限 | `annualLeave_expiryDate` |
| 補休時數 | `annualLeave_compensatoryHours` |
| 勞保投保薪資 | `laborInsuredSalary` |
| 勞退投保薪資 | `pensionInsuredSalary` |
| 健保投保薪資 | `healthInsuredSalary` |
| 眷口數 | `dependentCount` |

這 9 欄是選填：檔案裡沒有這些欄位也不會讓整批匯入失敗。

## 資料格式的處理

- **日期**：除了 `yyyy-mm-dd`，也接受民國年（`091/12/01`、`60/10/1`、`115年9月1日`）。年份 3 位數以內視為民國年。
- **數字**：可含千分位逗號（`45,800`）。
- **積假**：`3國` 這類數字加備註的寫法，取前面的數字，並在結果提醒。
- **非數字文字**：投保薪資欄出現 `已勞退`、`投65歲` 之類的文字時，該欄略過（維持 0 或原值），並在結果提醒。
- **自提勞退**：範本標題是「自提勞退 (%)」，但系統的 `laborPensionSelf` 是每月扣款金額。
  填 0～1 之間的數字（`0.06` = 6%）時，會依勞退投保薪資（沒有則勞保投保薪資、薪資金額）換算成金額；
  找不到可換算的基準時略過，並在結果提醒。
- **主管員工 ID**：
  - 可填同一份檔案內的員工編號（主管本人也可以在同一次匯入）。
  - 填成自己的編號時不設定直屬主管（避免自己簽自己）。
  - 被其他人指定為主管、且匯入預設權限為「員工」的新建帳號，會自動設為 `supervisor`。

## 更新既有員工

匯入參數「更新已存在的員工資料」：

- **關閉（預設）**：員工編號或 Email 已存在就停止匯入，錯誤訊息會一次列出所有有問題的列（最多 20 列）。
- **開啟**：以員工編號比對（找不到才用 Email）：
  - 已存在 → 更新檔案裡「有填」的欄位。空白儲存格不會清掉原有資料。
  - 不存在 → 新增。
  - 不會更動：帳號（username）、權限（role）、Email、密碼、員工編號。
  - Email 已被另一位員工使用時停止匯入。
  - 先寫入新增、再更新；有交易支援時全部成功才提交，失敗會回滾並回報失敗列號。

## 結果

回應包含 `createdCount`、`updatedCount`、`preview`（每筆有 `action`: `created` / `updated`），
以及 `warnings`（自動調整或略過的資料，匯入完成後請抽查）。
